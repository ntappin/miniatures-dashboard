Save tasks to GitHub

Tasks are saved in this site's GitHub repo. Paste a GitHub token to save from this browser; it stays in this browser only.

  1. Open GitHub's new fine-grained token page.
  2. Under Repository access, choose Only select repositories and pick miniatures-dashboard.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Generate the token and paste it here.
